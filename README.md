# C-Learning-Journey
My first step into programing
## 📁 Projects Overview
*   **calculator.c**: 命令行计算器，支持四则运算、除零处理，以及循环计算。
*   **scores.c / scores2.c**: 基于数组的成绩统计器，支持录入成绩、计算平均分和最高分。
*   **for_test.c**: for循环与嵌套循环的练习（如九九乘法表）。

## 🎯 Learning Goals
- 掌握 C 语言核心语法与底层逻辑（指针、结构体等）。
- 为后续学习 Python、OpenCV 及智能视觉工程打下坚实基础。
- 保持每日代码更新，积累项目经验。
